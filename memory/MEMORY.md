# Memory Index

Version-controlled in this repo so it syncs across the photographer's machines. Write new ones here
(`memory/<name>.md`), add a line below, and commit + push. `feedback-*` files are injected in full at every
session start.

**Starting defaults.** The `feedback-*` rules below shipped with the template: they were learned on another
photographer's shoots (`origin: template-default` in their frontmatter). They are good habits, not this
photographer's words. When this photographer says otherwise, their word wins: rewrite or delete the file via
`learn-from-feedback` (and set `origin: photographer` when they confirm or reshape a rule). Never keep two
rules that contradict each other.

- [The photographer](user-photographer.md): who they are, home base, languages, genres, team, limits, budget (filled by `onboard`)
- [Tools and access](reference-tools-and-access.md): OpenCLI browser, WhatsApp MCP, Places, Commons, image APIs
- [Real places, current look](feedback-real-places-current-look.md): verify with recent dated photos; show the year
- [Continuous story, one location](feedback-continuous-story-one-location.md): a short film, not a mood board
- [Bold means](feedback-bold-means.md): skin/attitude/light, not gimmicks; never nudity; never say "bold outfits"; ask after two misses
- [Image-first concepts](feedback-image-first-concepts.md): interesting real place + one killer image, light story, physics in `look`, audited frames
- [Shared board hygiene](feedback-shared-board-hygiene.md): no questions/unfinished notes; board language; label real vs AI
- [Boring test](feedback-boring-test.md): one-line hook; kill hobby-somewhere-pretty and copies of her feed; use her statement pieces; eye-catchers on top
- [Producible with own means](feedback-producible-with-own-means.md): no indoor space = outdoor; no rented studios/rigs unless asked; location-first; use places as found, no set dressing
- [Plan around the least mobile](feedback-plan-around-least-mobile.md): radius around the least mobile person; weekly-closure status + parking per place
- [Cheap, short-use locations](feedback-cheap-short-use-locations.md): hours not leases; price first; widen before "none"
- [In season](feedback-in-season.md): check every prop/plant/light against the shoot date
- [Full kit, honest light](feedback-use-full-kit-honest-light.md): every light they own, one gel when asked; one plan per frame on real ground, independent check
- [Identity and continuity](feedback-identity-and-continuity.md): her face, tattoo placement, owned outfits; review full size; regenerate drift; Nano Banana Pro only (`--strict`)
- [Learn from rejections](feedback-learn-from-rejections.md): understand, one question, save the general rule
- [Privacy and secrets](feedback-privacy-and-secrets.md): keys in the OS credential store, no personal details to third parties, WhatsApp read-only
