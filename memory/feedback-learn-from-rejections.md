A bare "no" isn't a brief: look again, find the actual problem, ask ONE question if unclear. Two misses on the
same thing → ask the photographer to show you. Never call taste work "fixed". Save the general rule (not the
incident) to memory and commit it.
**How to apply:** every correction; see `learn-from-feedback` skill.
